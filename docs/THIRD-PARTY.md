# Third-party assets

## Material Symbols

Files:

- `app/src/main/res/drawable/ic_action_*.xml`
- `app/src/main/res/drawable/ic_feedback.xml`
- `app/src/main/res/drawable/ic_star.xml`
- `app/src/main/res/drawable/ic_content_copy.xml`

These are action icons converted from the Material Symbols Outlined
font. They replace the old PNG set in toolbars and menus.

Copyright Google LLC. Licensed under the Apache License, Version 2.0.
The full license text is in `docs/licenses/Apache-2.0.txt`.

The outlines are the default instance of the variable font: `FILL` 0,
`wght` 400, `opsz` 24. They were extracted from
`MaterialSymbolsOutlined.woff2` as distributed in the Dart SDK
DevTools assets, decompressed with `woff2_decompress`. The converted
paths are committed; the font is not part of this repository.

Game icons (for example `fifteen.png`) and keypad art come from
upstream and keep the upstream license.
